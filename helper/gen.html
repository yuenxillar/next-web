Rust Struct Getter/Setter Generator

Input your Rust struct definition, and the system will automatically generate corresponding getter and setter methods. Supports standard structs and structs with named fields, properly handles Option types.

Input Struct Definition

Example 1: Basic Types

struct User { id: u64, username: String, active: bool, }

Example 2: With Option Types

struct Person { name: String, age: u32, email: Option<String>, phone: Option<String>, }

Example 3: Complex Types

struct Product { id: u32, name: String, price: f64, category: Option<String>, tags: Vec<String>, }

Features

  • Supports standard Rust struct syntax
  • Properly handles Option<String> types, getter returns Option<&str>
  • For Option types, setter accepts inner type instead of Option wrapper
  • Generated code follows Rust naming conventions and best practices

Generation Rules

  • For String fields: getter returns &str
  • For Option<String> fields: getter returns Option<&str>
  • For Option<T> fields: setter accepts T type parameter
  • All getter methods return references, setter methods accept ownership or references
