Rust 结构体 Getter/Setter 生成器

输入您的Rust结构体定义，系统将自动生成对应的getter和setter方法。 支持标准结构体和带有命名字段的结构体，正确处理Option类型。

输入结构体定义

示例 1: 基本类型

struct User { id: u64, username: String, active: bool, }

示例 2: 包含Option

struct Person { name: String, age: u32, email: Option<String>, phone: Option<String>, }

示例 3: 复杂类型

struct Product { id: u32, name: String, price: f64, category: Option<String>, tags: Vec<String>, }

功能说明

  • 支持标准Rust结构体语法
  • 正确处理Option<String>类型，getter返回Option<&str>
  • 对于Option类型，setter接受内部类型而不是Option包装
  • 生成的代码符合Rust命名约定和最佳实践

生成规则

  • 对于String字段：getter返回&str
  • 对于Option<String>字段：getter返回Option<&str>
  • 对于Option<T>字段：setter接受T类型参数
  • 所有getter方法返回引用，setter方法接受所有权或引用
